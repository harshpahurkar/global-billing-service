# Contributing

Thank you for considering contributing! Please see our issue templates for reporting bugs or requesting features.

## Development Setup

1. Clone the repo
2. `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and configure
4. Run `docker-compose up -d` for dependencies
5. Run `make test` to verify everything works

## Code Style

- Follow PEP 8 conventions
- Run `flake8` before submitting PRs
- Write tests for new features
